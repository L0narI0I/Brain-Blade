# Brain and Blade

## Présentation du jeu

Brain and Blade est un jeu de type "RPG" (Role Play Game) ou vous jouez un combattant qui devras mettre sa force et ses connaissances a dispositon afin d'obtenir le meilleur score possible !

Durant votre quête, vous enchaînerez combats et quizz de culture générale, et attention , il vous est essentiel de bien répondre aux question qui vous permetterons d'amélorier vous statistiques !

A la fin de chaque combas ou vous survivrez, une question vous seras posée, et si vous répondez correctement, vous pourrez choisir une statisqte qui sera augmentée proportionellement à la difficulté de la question qui vous à été posée !


Des captudes d'écran illustant les différentes interraction  du jeu avec le joueur sont disponibles dans le dossier "captures"


# Guide d'utilisation

Pour pouvoir jouer à Brain and Blade, nous vous invitons à suivre les étapes suivantes ;

dans le teminal, depuis le répertoire "Brain-Blade", entrez la commande:
> ijava compile Main.java

suivie de la commande :
> ijava execute Main

--> Le menu principal du jeu s'ouvre, laissez vous porter par les indications du jeu ;D !
